Distintivo temporal de AFK Farm para Minecraft 1.21.4, 1.21.11 y 26.2.

- El mod de cosméticos muestra «AFK FARM» sobre el jugador mientras el servicio confirma una sesión activa.
- El distintivo se retira al detener la sesión o cuando deja de renovarse, y solo se consulta en play.minelatino.com.
- El ranking del launcher incluye todas las cuentas activas, aunque aún tengan 0 horas registradas.
